# Memory Engine

Version: 1.0
Status: Draft
Author: Nurbek Andaqulov

---

# Purpose

Memory is one of Virel's defining features.

The goal is not to remember everything.

The goal is to remember what matters.

---

# Philosophy

Human memory is selective.

Virel should behave the same way.

Important information stays.

Unimportant information slowly disappears.

---

# Memory Types

## Identity Memory

Stores stable information about the user.

Examples:

- Name
- Preferred language
- Profession
- Interests

---

## Preference Memory

Stores user preferences.

Examples:

- Favorite programming language
- Favorite music
- Preferred communication style
- Favorite games

---

## Project Memory

Stores active projects.

Examples:

- Virel
- Portfolio
- Laravel Project

Projects remain active until completed.

---

## Conversation Memory

Stores recent conversations.

Useful for maintaining context.

Short-term only.

---

## Long-Term Memory

Stores information that should survive for months.

Examples:

- Long-term goals
- Important life events
- Permanent preferences

---

## Temporary Memory

Used only during the current conversation.

Destroyed after the conversation ends.

---

# Memory Lifecycle

New Information

↓

Evaluate Importance

↓

Classify

↓

Store

↓

Use

↓

Update

↓

Forget (if unnecessary)

---

# Importance Levels

Critical

Important

Useful

Temporary

Ignore

---

# Rules

Never store everything.

Never store sensitive information without reason.

Never repeat memories unnaturally.

Use memory only when it improves the conversation.

---

# Future Goal

Users should feel:

"It remembers me."

Not:

"It stores everything I say."
